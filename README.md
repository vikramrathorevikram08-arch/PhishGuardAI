# 🛡️ PhishGuardAI

### AI-Powered Phishing Detection System

**GitHub Repository:** [PhishGuardAI](https://github.com/vikramrathorevikram08-arch/PhishGuardAI)

PhishGuardAI is an intelligent security project designed to identify and detect potentially malicious URLs and phishing websites using machine learning and cybersecurity techniques.

## 🚀 Features

- 🔍 URL Analysis and Detection
- 🤖 AI/ML-Based Phishing Classification
- 🛡️ Protection Against Suspicious Websites
- 📊 Prediction of Safe and Malicious URLs
- ⚡ Fast and User-Friendly Interface

## 🛠️ Technologies Used

- Python
- Machine Learning
- Artificial Intelligence
- HTML, CSS, JavaScript
- Flask

## ⚙️ Installation and Setup

**1. Clone the repository**

```bash
git clone https://github.com/vikramrathorevikram08-arch/PhishGuardAI.git
```

**2. Open the project**

```bash
cd PhishGuardAI
```

**3. Create a virtual environment**

```bash
python -m venv .venv
```

**4. Activate virtual environment (Windows)**

```bash
.venv\Scripts\activate
```

**5. Install dependencies**

```bash
pip install -r requirements.txt
```

**6. Run the application**

```bash
python app.py
```

## 🎯 Project Objective

The main objective of PhishGuardAI is to improve online security by identifying phishing URLs and helping users avoid potentially harmful websites.
